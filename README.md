<br>This is the Yu-Gi-Oh! plugin for LackeyCCG.
# Features
* Series 10 card layout (we are too lazy to use newer ones).
* Over 1000 cards are available, including OCG exclusive and modern cards.
* Most of the cards use the current Problem-Solving Card Text (abbreviated as PSCT).
* Including Pre-Errata card effects, Anime/Manga cards, and Custom cards.
* Up to 5 alternate artwork per card (plus both Japanese and International artwork).
* Many of the Token Cards.
* Booster Packs for specific Card Types (plus Pre-Errata and Anime/Manga exclusive).
